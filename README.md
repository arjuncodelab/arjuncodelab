### Feature Projects

#### Projects

##### [Quantium Retail Analytics: Customer Insights & Store Trial Performance](https://github.com/arjuncodelab/python_analysis_quantium_job_simulation_tasks) — Python
- **Tools:** Python, Pandas, NumPy, SciPy, Matplotlib, Seaborn
- Cleaned 264K transactions from July 2018 to June 2019 using Pandas and NumPy. Extracted pack sizes, normalized brand categories, and segmented customers by life stage and premium tier to identify purchasing patterns. Optimized data types to reduce memory usage by 50.8%.
- Matched three control stores using correlation and min-max distance, then evaluated a five-month layout trial with SciPy. Measured revenue lifts of 21.6% at Store 77, 8.4% at Store 86, and 13.2% at Store 88; identified a 20% increase in footfall as the main growth driver.
- Visualized revenue trends, customer traffic, and transaction volume using Matplotlib and Seaborn.

##### [Student Digital Wellbeing Analytics](https://github.com/arjuncodelab/student_digital_wellbeing_analytics) — Python, SQL
- **Tools:** SQL, Python, Pandas, NumPy, Matplotlib, Seaborn
- Designed a normalized relational schema and ETL process to transform flat survey data into relational tables containing 500K student records.
- Used SQL joins, window functions (`PERCENT_RANK`), and conditional aggregation to answer nine business questions. Students in the highest internet-use group had an average well-being score of 52.2, compared with 62.4 for the lowest-use group. Students with high “brain-rot” scores showed an 11.5% attendance drop and a 10.4% productivity decline.
- Validated key findings with ANOVA and created visualizations in Python.
- Added B-tree indexes, reducing a benchmark query on 500K rows from 0.708 seconds to 0.0011 seconds.

##### [Agri Market Analysis](https://github.com/arjuncodelab/agri-market-analysis) — SQL
- **Languages:** SQL, PostgreSQL
- Analyzed 600K+ agricultural transactions across Maharashtra, Uttar Pradesh, and Karnataka using SQL window functions and CTEs to identify regional price volatility.
- Found weekly price crashes exceeding 30% in high-volatility regions, including Sholapur and Nashik, and identified “static markets” with no vendor competition to inform procurement strategy.
- Built a PostgreSQL star schema with B-tree indexing. Data-quality audits flagged entry anomalies, such as minimum prices exceeding maximum prices, before reporting.

##### [E-Commerce Sales & Delivery Analytics Dashboard](https://github.com/arjuncodelab/E-Commerce_Sales__Delivery_Analytics_Dashboard) — Power BI
- **Tools:** Power BI, Power Query, DAX, data storytelling, data visualization
- Built a four-page Power BI dashboard using 99,000 orders from the public Brazilian Olist e-commerce dataset, covering sales, categories, sellers, payments, and delivery.
- Modeled nine related tables and wrote 20+ DAX measures in a dedicated measures table, covering sales, freight, delivery time, delayed and canceled orders, and year-to-date metrics.
- Found that credit cards accounted for about 78% of the paid amount. Canceled orders took an average of 18.4 days to deliver, compared with 10.8 days for delivered orders.
