### Feature Projects

#### Projects

##### [Quantium Retail Analytics: Customer Insights & Store Trial Performance](https://github.com/arjuncodelab/python_analysis_quantium_job_simulation_tasks) — Python
- **Tools:** Python, Pandas, NumPy, SciPy, Matplotlib, Seaborn
- Cleaned 264K transactions, segmented customers by life-stage and premium tier, and measured a store-trial against matched control stores.
- Revenue lifts: 21.6% (Store 77), 8.4% (Store 86), and 13.2% (Store 88).

##### [Student Digital Wellbeing Analytics](https://github.com/arjuncodelab/student_digital_wellbeing_analytics) — Python, SQL
- **Tool:** SQL, PostgreSQL, Python, Pandas.
- Turn flat survey data into a normalized relational database of 500K students records and answered 9 business questions with SQL (joins, window functions, conditional aggregation.) Validated key findings with  ANOVA and added B-Tree indexes that cut a benchmark query  to about  a milliseconds.

##### [Agri Market Analysis](https://github.com/arjuncodelab/agri-market-analysis) — SQL
- **Tool:** SQL, PostgreSQL
- Analyzed 600K+ agricultural transactions across Maharashtra, Uttar Pradesh, and Karnataka using SQL window functions and CTEs. Found weekly price crashes above 30% in high-volatility regions, built a PostgreSQL star schema with B-tree indexing. Data-quality.

##### [E-Commerce Sales & Delivery Analytics Dashboard](https://github.com/arjuncodelab/E-Commerce_Sales__Delivery_Analytics_Dashboard) — Power BI
- **Tools:** Power BI, Power Query, DAX, data storytelling, data visualization
- 4-page Power BI dashboard using 99,000 orders from the public dataset with a 9-table model and 20+ DAX measures..
- Found that credit cards accounted for about 78% of the paid amount, Canceled orders took longer to deliver than delivered ones (18.4 vs 10.8 days).
